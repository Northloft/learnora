# Organisation logos

The Learning network strip on the homepage shows a logo for each organisation once a file is added here. Until then it shows a neutral monogram and the organisation's name.

1. Get each logo from the organisation itself (their brand or press page) and confirm you may display it.
2. Save it here as SVG (preferred) or PNG, on a transparent background, about 440 px wide. Suggested names: `iit-guwahati.svg`, `opju.svg`, `csvtu.svg`, `gpcet.svg`, `rcew.svg`, `msme.svg`, `startup-india.svg`, `opju-innovation-center.svg`, `erkey-montors.svg`, `jpl.svg`.
3. In `js/data/home.js`, set `"logo": "assets/logos/<file>"` on that organisation. No other change is needed.

Only show a logo for an organisation you have confirmed the relationship with.
